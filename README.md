# Haikyu Fly High - Player & Team Stats Calculator (In Progress)

**Project Type:** Python / Data Processing / Automation  
**Status:** In Progress  

---

## Overview

This project is a **Python-based tool** for calculating and analyzing player and team statistics in the game *Haikyu Fly High*. It demonstrates event-driven programming, data parsing, and automation principles applied in a game simulation context.

The project is a personal learning initiative aimed at strengthening:

- Python scripting and automation skills  
- Data parsing and structured data analysis  
- Debugging, testing, and modular code design

---

## Key Features (Implemented / Planned)

- Parse structured player and match data from CSV or log files  
- Calculate per-player stats (e.g., attack success, blocks, serve efficiency)  
- Aggregate team-level performance metrics  
- Export calculated statistics to CSV or JSON  
- Modular and extensible code design for additional game features  
- Command-line interface for testing and analysis  

---

## Technologies

- **Python** – primary development language  
- **Pandas / NumPy** – data processing and calculations  
- **JSON / CSV** – input/output data formats  
- **Event-driven programming** – triggers calculations based on match events  
- **Unit testing** – for verification of calculation accuracy  

---

## Current Status

- Core data parsing and stat calculation functions implemented  
- CLI interface for testing calculations functional  
- Ongoing: integration with multiple data sources and output reporting  

---

## Learning Goals
